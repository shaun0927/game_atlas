# game_atlas

게임 도메인의 지식·제작 워크플로우·노하우·배경지식·게임 엔진 등을 체계적으로 정리하는 지식 아틀라스.

각 이슈는 하나의 지식 축(axis)을 담당하며, 서로 교차 참조된다. 같은 주제의 중복 이슈는 가장 깊이 있는 하나(canonical)로 통합하고, 독창적 관점은 흡수한다.

## 원칙
- 각 이슈는 독립된 지식 축이면서 다른 축과 교차한다.
- 중복 이슈는 canonical 하나로 통합하고, 독창적 관점은 흡수한다.
- "좋다/재미있다"가 아니라 "왜 그렇게 느껴지는가, 어떻게 설계할 수 있는가"를 남긴다.
- 이슈 형식: 연구 계기 → 핵심 결론 → 구조적 분해 → 다른 축과의 연결 → 질문/체크리스트.
